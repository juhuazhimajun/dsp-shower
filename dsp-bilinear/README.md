## 二、三个实验怎么用

### 实验 1：听（7 段音频，全部 44.1 kHz 播放）

下表说明每段音频是什么、以及「该听出什么」——照着听，一分钟就能分辨混叠和「变闷」的区别。

▸ 符号：$f_{s}$ = 采样率（单位 Hz）；Nyquist 频率 = $f_{s}/2$，超过它的成分会被折回 $0\sim f_{s}/2$。

| 文件 | 是什么 | 该听出什么 |
|---|---|---|
| `A1_扫频_原声.wav` | 200 Hz→7.6 kHz 扫频 6 s | 一路向上的警笛 |
| `A2_扫频_8k采样_无抗混叠.wav` | 同一扫频，按 8 kHz 取样 | **第 3 秒音高「掉头」往下**（4 kHz 折返） |
| `A3_扫频_先低通再8k采样.wav` | 先 3.4 kHz 低通再取样 | 升到 3.3 kHz 就断掉，**不掉头** |
| `B1_纯音_6k真身_采样后_2k真身.wav` | ① 6 kHz ② 6 kHz 过 8 kHz 采样 ③ 真 2 kHz | **②和③一模一样**：8 kHz−6 kHz=2 kHz |
| `C1_星星_原声.wav` | 小星星，14 次谐波 | 正常乐器音色 |
| `C2_星星_2.6k采样_电音.wav` | 2.6 kHz 采样 | 金属感 / 合唱感（5 次谐波偏 16 Hz，拍频） |
| `C3_星星_1.6k采样_重电音.wav` | 1.6 kHz 采样 | 8-bit 破碎感 |

每段音频在网页里都配了「波形 + 时频谱」图。**看时频谱比听更直观**：A2 的谱线是一个「Λ」形——上行到 4 kHz 再镜像下行。

### 实验 2：拖（s 平面 → z 平面）

左图 s 平面上的黑星可以拖（也可以直接点）。右图实时显示四种映射把它搬到 z 平面的哪里，并着色显示**整个左半平面**的去向：

- **绿点** = 来自 $\sigma<0$（模拟稳定）；**红点** = 来自 $\sigma\ge0$。
- 判据：**绿点跑到单位圆外 ⇒ 模拟稳定、数字不稳定**。

把 `T` 从 1 拖到 3 或 0.3，能看见映射整体缩放。下面那张表会给出每种方法的 $z$、$\lvert z\rvert$ 和判定。

### 实验 3：调（滤波器频谱）

4 阶 Butterworth 低通经双线性变换后的幅频响应。拖 $\Omega_p$、改阶数 $n$、勾/取消「预扭曲」：

- 勾上（预扭曲）：曲线在 $\Omega_p$ 处正好 $-3\ \mathrm{dB}$。
- 取消：截止点跑到 $2\arctan(\Omega_p/2)$，$\Omega_p$ 越靠近 $\pi$ 偏得越厉害（$\Omega_p=0.45\pi$ 时 $-3\ \mathrm{dB}$ 点掉到 $0.392\pi$，通带内先亏 7.4 dB）。

## 三、结论（含一处更正）

下表把四种映射放在同一张表里对比：**稳定性、有没有混叠、频率畸变有多严重、能不能做高通**。

▸ 符号：$s=\sigma+j\omega$ 是拉普拉斯变量（横轴 $\sigma$ 管衰减/增长，纵轴 $j\omega$ 是模拟频率）；$z$ 是 Z 变换变量（单位圆内稳定）；$T$ 是采样周期，网页里归一化为 $T=1$；$\Omega$ 是数字角频率（$\Omega=\pi$ 对应 Nyquist），$\lvert z\rvert$ 决定稳定与否。

| 方法 | 稳定性 | 混叠 | 频率畸变 | 能不能做高通 |
|---|---|---|---|---|
| 脉冲响应不变 $z=e^{sT}$ | 稳定 | **有（严重）** | 无（线性） | **不能** |
| 前向差分 $z=1+sT$ | **不稳定**（$\sigma<0$ 也可能 $\lvert z\rvert>1$） | 无 | 极严重 | 不能 |
| 后向差分 $z=\dfrac{1}{1-sT}$ | 稳定 | 无 | 极严重（高频被挤在 $z=1$） | 勉强、但高频不可用 |
| 双线性 $z=\dfrac{1+sT/2}{1-sT/2}$ | **稳定** | **无** | 有（$\omega T=2\tan\frac{\Omega}{2}$） | **能** |

> **更正**：之前口头说的「反向差分法稳定性不保」是错的。
> 真正不稳定的是**前向**差分（$s=\frac{z-1}{T}$）：左半平面被搬到 $\lvert z-1\rvert<1$，有一部分在单位圆外。
> **后向**差分（$s=\frac{1-z^{-1}}{T}$）把左半平面搬到 $\lvert z-\frac12\rvert<\frac12$，**严格在单位圆内，一定稳定**；它的毛病是**把高频挤没了**——整条 $j\omega$ 轴被压成半径 $\frac12$ 的小圆。
> 考试就写这一句：「前向差分不稳定；后向差分稳定但频率畸变严重」。

## 四、和考试的关系（T11 双线性 IIR 设计）

这五步就是网页第 5 节列的那五步，也是判分点所在。

先约定符号：$\Omega_p,\Omega_s$ 是**数字**通带/阻带边缘角频率（单位 rad，$\Omega=\pi$ 对应 Nyquist）；$\omega_p,\omega_s$ 是预扭曲后对应的**模拟**角频率（单位 rad/s）；$A_p$ 是通带允许的最大衰减（dB），$A_s$ 是阻带要求的最小衰减（dB）；$n$ 是阶数；$\omega_c$ 是模拟 3 dB 截止角频率。

1. **预扭曲**：$\omega_p=\dfrac{2}{T}\tan\dfrac{\Omega_p}{2}$，$\omega_s=\dfrac{2}{T}\tan\dfrac{\Omega_s}{2}$。
   ▸ 作用：把数字指标换算到模拟轴上，这样后面查巴特沃斯原型表才对得上（否则截止点会偏，见 `fig2` 的 (c)）。
2. **求阶数**：$n=\left\lceil\dfrac{\lg\frac{10^{A_s/10}-1}{10^{A_p/10}-1}}{2\lg\frac{\omega_s}{\omega_p}}\right\rceil$，$\omega_c=\omega_p\left(10^{A_p/10}-1\right)^{-1/(2n)}$。
   ▸ 作用：$n$ 决定滚降有多陡，$\omega_c$ 决定曲线左右平移；这一步用的必须是**预扭曲之后**的 $\omega$。
3. **反归一化**：把归一化原型中的 $s/\omega_c$ 换成 $s$。
   ▸ 作用：把「$\omega_c=1$ 的标准巴特沃斯」缩放成你要的截止频率，得到 $H_{a}(s)$。
4. **双线性代入**：$s=\dfrac{2}{T}\dfrac{z-1}{z+1}$，整理成 $z^{-1}$ 的多项式，得 $H(z)$。
   ▸ 推导：不需要额外证明，这就是双线性的定义式（它由 $s=\frac{2}{T}\frac{1-z^{-1}}{1+z^{-1}}$ 两边同乘 $z$ 得到）。
5. **验算**：$z=1$（即 $\Omega=0$）看直流增益，$z=-1$（即 $\Omega=\pi$）看高频衰减，再核 $\Omega_s$ 处是否够 $A_s$。
   ▸ 作用：这三处最容易被算错，且都是独立可查的（不用重算整条曲线）。

对应模板见课程讲义《题型手册（下）》的 T11 一节（本仓库不包含该讲义，只列口径）。

## 六、技术说明（怕你怀疑「是不是做手脚了」）

- **音频模型**：先按 $f_s$ 在连续公式上**直接取样**（= 理想 ADC、**没有**抗混叠滤波），再用 **FFT 带限重建**升到 44.1 kHz 播放（= 理想 DAC）。
  - 不用「零阶保持」：它会引入 $k f_s\pm f$ 的镜像，听起来比真实混叠更脏，等于作弊。
  - 也不用短 FIR 插值：8k−f 的镜像只能压到 −40 dB，时频谱上会画出一条**假的高频斜线**，容易被误读成「混叠翻到高频去了」。（这版就是踩过这个坑之后改的。）
- **dB 口径**：时频谱按「满幅正弦 = 0 dB」归一化，色标 −90…−5 dB。
- **归一化**：网页里的 $T$ 取 1（等价于 $f_s=1$），只影响坐标刻度，不影响结论。
- **图 1 的「越界比例」**：对 $s$ 平面网格逐点判断 $\lvert z\rvert>1$。前向差分的越界比例在 85% 上下（matplotlib 图用 25×33 网格，实算 85%；网页互动图用 33×47 网格，实算 87%）——网格不同数会跳，结论不变：左半平面被搬进了 $|z-1|<1$，有一部分落在单位圆外。
- 环境：Python 3.14（numpy / scipy / matplotlib）、MATLAB R2024b。
